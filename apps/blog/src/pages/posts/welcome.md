# Welcome to Minions Crm-pipeline

We're excited to introduce **Minions Crm-pipeline** — Deal stages, transitions, revenue forecasts, and win/loss tracking.

## What's Included

- **TypeScript SDK**: `npm install @minions-crm-pipeline/sdk`
- **Python SDK**: `pip install minions-crm-pipeline`
- **CLI**: `npm install -g @minions-crm-pipeline/cli`

Check out the [documentation](https://crm-pipeline.minions.help) for a full guide.
