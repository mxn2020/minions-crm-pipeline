# Minions Crm-pipeline

Deal stages, transitions, revenue forecasts, and win/loss tracking

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-crm-pipeline/sdk`) — Core library for Node.js
- **Python SDK** (`minions-crm-pipeline`) — Python bindings
- **CLI Tool** (`@minions-crm-pipeline/cli`) — Command-line interface
- **Web App** — Interactive playground at [crm-pipeline.minions.wtf](https://crm-pipeline.minions.wtf)
